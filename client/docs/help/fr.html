Présentation et termes

L’Add-on Store intègre directement dans Tungsten Power PDF les extensions du programme. Vous trouvez les modules dans un catalogue, vous consultez leur description, leurs captures d’écran et leurs évaluations, puis vous les installez, les mettez à jour ou les supprimez en un clic. Le store se tient lui-même à jour, tout comme vos modules, et vous signale quand une mise à jour de Power PDF est disponible.

Ce manuel décrit le client : le module dans Power PDF avec la fenêtre du store. Le site web du store et le portail destiné aux développeurs et aux administrateurs du serveur du store sont décrits dans le manuel général de l’Add-on Store.

Ce que fait l’Add-on Store

  • Il affiche le catalogue des modules dans la langue de Power PDF : nom, description, catégorie, version, taille, auteur, captures d’écran, évaluations et « Nouveautés de la » version actuelle.
  • Il installe, met à jour et supprime des modules ; chaque modification demande une seule autorisation d’administrateur.
  • Il n’installe que des paquets vérifiés et signés : la signature du store et la somme de contrôle (SHA-256) sont vérifiées avant toute copie.
  • Il annonce les nouvelles versions : un point sur le bouton du ruban, la vue Mises à jour disponibles et, si vous le souhaitez, un avertissement unique.
  • Il se met à jour lui-même : Power PDF se ferme, le nouveau programme d’installation s’exécute, puis Power PDF redémarre.
  • Il recherche selon le besoin : vous décrivez ce dont vous avez besoin, le store propose les modules adaptés.
  • Il débloque des modules pour votre organisation grâce à un code client fourni par votre fournisseur de modules.
  • Il transmet les problèmes et les suggestions au développeur d’un module, avec des pièces jointes et, si vous le souhaitez, le journal.
  • Il vous permet d’évaluer les modules avec des étoiles.
  • Il détecte les modules bloqués et propose de les supprimer.
  • Il désactive puis réactive les modules que le store met temporairement hors service, sans les supprimer.

Aide

L’Add-on Store fournit une aide commune à tous les modules installés, dans laquelle vous effectuez une recherche dans tous les textes d’aide à la fois. Vous l’ouvrez ainsi :

  • dans l’onglet Fonctions avancées, avec le bouton Aide (tout à droite, groupe Aide) ;
  • dans la fenêtre du store, avec Aide en haut à droite ou avec F1 : l’aide s’ouvre directement au chapitre consacré à cette fenêtre ;
  • dans chaque module, avec son bouton d’aide ou F1 : l’aide s’ouvre au chapitre correspondant du module ;
  • dans la fenêtre classique, avec Aide ; sur la page d’options, avec l’aide de Power PDF.

À gauche figurent les modules installés ; un clic affiche ou masque leurs chapitres. À droite s’affiche le chapitre sélectionné, avec Précédent et Suivant en bas et Imprimer le chapitre en haut. Saisissez un ou plusieurs mots dans Rechercher dans l’aide, en haut : les résultats apparaissent immédiatement, avec le module, le chapitre et un extrait ; les majuscules, les minuscules et les accents n’ont pas d’importance, et tous les mots doivent figurer dans le texte. Les flèches vers le haut et vers le bas sélectionnent un résultat, Entrée l’ouvre avec les termes recherchés mis en évidence, Échap efface la recherche. Les liens vers des sites web s’ouvrent dans le navigateur. F1 dans la fenêtre d’aide affiche cette section.

L’aide s’affiche dans la langue de Power PDF lorsqu’un module la fournit dans cette langue, sinon en anglais. L’aide de l’Add-on Store est disponible en anglais, français, italien, allemand, espagnol et néerlandais.

Configuration requise et installation

Configuration requise

  • Tungsten Power PDF Business SaaS (avec connexion), version 2025.3.7 ou ultérieure. Dans Power PDF 2025, seule l’édition Business charge des modules ; à partir de 2026.4, toutes les éditions le font (Standard, Advanced, Business).
  • Le programme d’installation refuse un Power PDF sous licence avec un numéro de série ; l’Add-on Store est destiné uniquement à Power PDF avec connexion.
  • Windows 10 ou 11, x64 ou ARM64.
  • Pour la fenêtre moderne du store, le runtime Microsoft WebView2 (généralement présent sous Windows 10 et 11). Sans lui, c’est la fenêtre classique qui s’ouvre.
  • Une connexion HTTPS (port 443) vers le serveur du store, directe ou via le proxy du système.
  • Pour installer, mettre à jour et supprimer des modules : des droits d’administrateur local (une demande par action).

Installation

  1. Sur le site web de l’Add-on Store, choisissez Télécharger l’Add-on Store. Vous obtenez le programme d’installation PluginStore.msi.
  2. Fermez Power PDF et lancez le programme d’installation. Lors du premier téléchargement, Windows SmartScreen peut afficher un avertissement ; choisissez alors Informations complémentaires, puis Exécuter quand même.
  3. Lisez la licence, cochez J'accepte la licence et choisissez Installer. Windows vous demande une seule fois des droits d’administrateur.
  4. Démarrez Power PDF. Le ruban affiche l’onglet Store avec le bouton Add-on Store.

Le programme d’installation trouve Power PDF tout seul (via HKLM\SOFTWARE\Kofax\PDF\V1, sinon via App Paths) et s’installe dans son dossier bin\Plug-Ins. Si Power PDF est encore ouvert, le programme d’installation propose de le fermer puis de le redémarrer ensuite. Le programme d’installation existe dans les 21 langues de Power PDF ; Windows choisit la langue de l’utilisateur.

Désinstallation

Supprimez Add-on Store for Tungsten Power PDF dans les Paramètres de Windows, sous Applications, Applications installées. Le programme d’installation ne supprime que les fichiers propres au store ; les modules que vous avez installés restent dans Power PDF. Supprimez-les d’abord dans la fenêtre du store si vous n’en avez plus besoin.

Prise en main rapide

  1. Dans l’onglet Store, cliquez sur Add-on Store. La fenêtre du store s’ouvre.
  2. Parcourez la liste des modules à gauche, ou saisissez un terme dans Rechercher des modules en haut.
  3. Cliquez sur un module. Sa description, ses captures d’écran et ses évaluations apparaissent à droite.
  4. Choisissez Installer et confirmez. Windows vous demande une seule fois des droits d’administrateur.
  5. Lorsque le redémarrage vous est proposé, choisissez Redémarrer maintenant. Power PDF ne charge les modules qu’au démarrage ; il vous est d’abord proposé d’enregistrer les documents non enregistrés.

Après le redémarrage, le module se trouve dans l’onglet Fonctions avancées (ou à l’endroit indiqué dans sa description).

La fenêtre du store

La fenêtre s’ouvre dans une taille adaptée (environ 1000 × 680 points, jamais plus grande que l’écran) et affiche immédiatement le dernier catalogue chargé ; elle récupère le catalogue actuel en arrière-plan. Tant que le premier catalogue n’est pas disponible, un indicateur de chargement tourne.

L’en-tête

  • Rechercher des modules : le champ de recherche (chapitre Rechercher et filtrer).
  • Code client : gère les codes client (chapitre Codes client). Une coche indique qu’un code est actif.
  • Tous les modules : uniquement dans la vue Mises à jour disponibles ; revient à la liste complète.
  • Aide : ouvre l’aide au chapitre consacré à cette fenêtre (également avec F1).

Bandeaux

Sous l’en-tête, des barres colorées apparaissent sur toute la largeur de la fenêtre lorsque c’est nécessaire : une nouvelle version de l’Add-on Store, une mise à jour de Power PDF, des modules bloqués, des modules d’une installation précédente de Power PDF, un verrouillage par le service informatique ou une erreur de connexion. Les chapitres Mises à jour et Autres indications dans la fenêtre les expliquent.

Catégories et auteur

Sous les bandeaux se trouvent les boutons de catégorie : Tous et un bouton par catégorie. Avec un code client actif, le bouton Pour, suivi du nom de votre organisation, apparaît en premier ; il n’affiche que les modules qui vous sont fournis. Lorsque les modules proviennent d’au moins deux auteurs, vous pouvez en choisir un sous Auteur.

La liste

À gauche, les modules apparaissent sous forme de lignes avec icône, nom, description courte et étoiles. En haut se trouve la section Installés avec le nombre de modules installés et, le cas échéant, Mises à jour avec leur nombre ; en dessous, Autres modules. Parmi les modules installés, ceux fournis avec un code client viennent en premier, puis ceux que vous avez installés vous-même, puis ceux qui ne sont plus proposés ; dans chaque groupe, les mises à jour d’abord, puis par ordre alphabétique.

En dessous figure la remarque indiquant que l’installation et la mise à jour nécessitent des droits d’administrateur.

La fenêtre classique

Sans le runtime WebView2, ou lorsque le service informatique définit ClassicUI, une fenêtre simple s’ouvre : une liste avec les colonnes Plug-in, Disponible, Installée, État, Taille, Auteur et Contact, la description en dessous, et les boutons Mettre à jour le Add-on Store, Avertissement, Aide, Actualiser (recharger le catalogue), Désinstaller, Installer et Fermer. Les codes client, les évaluations, les signalements de problèmes, la recherche selon le besoin et la vue des mises à jour n’y sont pas disponibles.

Rechercher et filtrer

Pendant la saisie

Ce que vous saisissez dans Rechercher des modules filtre immédiatement la liste par nom, description et auteur. Les majuscules et minuscules n’ont pas d’importance. La catégorie et l’auteur s’appliquent en plus. Si rien ne correspond, la liste indique « Aucun module trouvé. »

Recherche selon le besoin

Décrivez avec vos propres mots ce dont vous avez besoin, par exemple « séparer des factures par code-barres », puis appuyez sur Entrée (au moins deux caractères). Le serveur du store recherche les modules adaptés et les classe ; lorsque l’assistant IA du store est activé, chaque résultat est accompagné d’une courte justification. La barre affiche « Meilleurs résultats pour : … » ou « Aucun module trouvé pour : … ». Tout afficher, Échap ou la poursuite de la saisie mettent fin à la recherche selon le besoin.

Installer, mettre à jour, supprimer

Installer

  1. Choisissez Installer. Confirmez la question « Installer « … » version … maintenant ? » avec Installer.
  2. Le client télécharge le paquet, vérifie la somme de contrôle et la signature, puis demande une seule fois des droits d’administrateur. Pendant ce temps, « Installation… » s’affiche.
  3. Après la copie, il demande si Power PDF doit redémarrer. Redémarrer maintenant ferme Power PDF (il vous est proposé d’enregistrer les documents non enregistrés) et le relance ; avec Plus tard, le module est chargé au prochain démarrage.

Un module qui nécessite une version plus récente de Power PDF affiche « Nécessite Power PDF … ou ultérieur » à la place de Installer.

Mettre à jour

Pour une mise à jour, choisissez Mettre à jour, dans la liste, dans les détails ou dans Mises à jour disponibles. Le déroulement est le même que pour l’installation. Le store ne propose que des versions plus récentes ; une version plus ancienne ne remplace jamais une version installée.

Supprimer

Choisissez Supprimer et confirmez « Supprimer « … » de Power PDF maintenant ? ». Après l’autorisation d’administrateur, le client efface le fichier du module, son dossier de données et ses paramètres utilisateur. Power PDF décharge le module au prochain démarrage. Le store ne peut supprimer que les modules qu’il a lui-même installés (reconnaissables au fichier manifest.json dans le dossier de données du module) ; il reconnaît aussi de cette façon les modules issus d’une installation manuelle (chapitre Liens depuis le site web, installation manuelle).

Ce qui vous protège

  • Seul ce qu’un store de confiance a signé est installé, et la somme de contrôle SHA-256 doit correspondre. Les deux sont vérifiées une nouvelle fois avant la copie, dans un dossier où seuls les administrateurs ont le droit d’écrire.
  • Le client communique uniquement avec le serveur du store configuré, via HTTPS (TLS 1.2 ou ultérieur), et ne suit aucune redirection.
  • L’étape avec droits d’administrateur ne s’exécute que lorsque vous installez, mettez à jour ou supprimez ; tout le reste s’exécute avec vos droits habituels.

Mises à jour

Comment le store trouve les mises à jour

Environ 15 secondes après le démarrage de Power PDF, et peu après la fermeture de la fenêtre du store, le client lit le catalogue en arrière-plan. S’il trouve une version plus récente de l’Add-on Store ou d’un module installé, les boutons Add-on Store et Mises à jour reçoivent un point orange. Lorsque l’indication des mises à jour de Power PDF est activée, une mise à jour de Power PDF compte également.

La vue « Mises à jour disponibles »

Le bouton Mises à jour de l’onglet Aide ouvre la fenêtre du store dans cette vue. Elle affiche une carte pour Power PDF, une pour l’Add-on Store et une pour chaque module installé ayant une mise à jour, chacune avec « Installée : … · Nouvelle : … » et le texte « Nouveautés ».

  • Mettre à jour ou Supprimer pour chaque module ; avec plusieurs mises à jour, Tout mettre à jour (l’une après l’autre, avec une seule question de redémarrage à la fin).
  • Mettre à jour le Add-on Store sur la carte du store (section ci-dessous).
  • Nouveautés et Masquer sur la carte de Power PDF.
  • Tous les modules, en haut à droite, mène à la liste complète. S’il n’y a rien à mettre à jour, la vue indique « Tout est à jour. »

Avertissement unique

Lorsque l’option M'avertir une fois de chaque nouvelle mise à jour est activée (par défaut), Power PDF pose une seule fois la question pour chaque nouvelle mise à jour : « Des mises à jour sont disponibles : … Ouvrir l'Add-on Store maintenant ? ». Oui ouvre la vue Mises à jour disponibles. L’avertissement ne réapparaît pas pour la même mise à jour. Si une boîte de dialogue est ouverte, l’avertissement attend qu’elle soit fermée.

Mettre à jour l’Add-on Store lui-même

Lorsqu’une nouvelle version du store est disponible, la barre « Une nouvelle version du Add-on Store est disponible : … (installée : …) » apparaît en haut avec Mettre à jour le Add-on Store. Le client télécharge le paquet, vérifie la somme de contrôle et la signature, puis demande : « Power PDF se ferme pour la mise à jour, … ». Après Oui, Power PDF se ferme, le nouveau programme d’installation s’exécute avec une barre de progression (une demande d’autorisation d’administrateur) dans la langue de Power PDF, puis Power PDF redémarre automatiquement, même si l’installation a été annulée.

Indication des mises à jour de Power PDF

Lorsque les administrateurs du store proposent une mise à jour pour votre version de Power PDF, le haut de la fenêtre affiche « Une mise à jour de Power PDF est disponible : … », avec Nouveautés (ouvre les notes de version officielles de Tungsten Automation dans le navigateur) et Masquer (jusqu’à la prochaine version plus récente). Le store ne peut pas installer Power PDF : « La mise à jour est installée par votre service informatique ou une personne disposant des droits d'administrateur. » L’option correspondante se trouve sur la page d’options.

Nouveautés, évaluations, signalements

Nouveautés

Après une mise à jour, effectuée par le store, par le service informatique ou par la mise à jour automatique, la fenêtre du store affiche une fois Nouveautés à sa prochaine ouverture : le texte de la nouvelle version pour chaque module et pour le store. Compris ferme cet aperçu. Ce que vous avez installé vous-même dans la fenêtre du store est considéré comme déjà vu.

Évaluations

Chaque module affiche sa note moyenne et le nombre d’évaluations. Vous évaluez les modules installés sous Votre évaluation, avec une à cinq étoiles ; un nouveau clic modifie l’évaluation. Une seule évaluation compte par installation. Pour les modules non installés, la fenêtre indique « Installez le module pour l'évaluer. »

Signaler un problème

  1. Dans les détails, choisissez Signaler un problème (pour le store lui-même, Signaler un problème avec l'Add-on Store en bas).
  2. Choisissez Problème ou Commentaire ou suggestion et décrivez ce qui s’est passé (au moins cinq caractères, au plus 4000).
  3. Si vous le souhaitez, saisissez une adresse dans E-mail pour les questions, cochez Joindre le journal des dernières actions du store et ajoutez jusqu’à 3 fichiers avec Joindre des fichiers (PNG, JPEG, PDF, TXT, LOG ; 5 Mo au maximum chacun, 10 Mo au total).
  4. Choisissez Envoyer.

Le signalement est envoyé au développeur du module, avec les versions du module, de Power PDF et de Windows ; aucun document n’est transmis. Ne joignez pas de documents confidentiels.

Codes client

Un code client débloque les modules que votre fournisseur de modules fournit à votre organisation. Il se présente ainsi : XXXX-XXXX-XXXX-XXXX-XXXX.

  1. Dans l’en-tête, choisissez Code client.
  2. Saisissez le code et choisissez Ajouter un code. Le store le vérifie et indique par exemple « Code valide pour … : 3 module(s) débloqué(s). »
  3. Choisissez Fermer. Les modules débloqués apparaissent dans la liste avec le libellé « Pour … » et sous le bouton de catégorie Pour.

Codes client sur cet ordinateur répertorie chaque code (abrégé) avec l’organisation, les modules débloqués et, lorsque la livraison est limitée, les installations utilisées, par exemple « Installations : 3/10 ». Jusqu’à 10 codes sont possibles.

Supprimer le code demande « Supprimer le code client de … ? ». Les modules fournis uniquement avec ce code sont également supprimés de Power PDF (une seule confirmation administrateur) ; si celle-ci est refusée, le code est conservé. Lorsque le service informatique définit les codes par stratégie, la boîte de dialogue indique « Votre service informatique gère le code client sur cet ordinateur. » et rien ne peut être modifié.

Code client depuis un site web : certaines pages client du store (par exemple www.power-pdf.de/finance) indiquent un code client. Le bouton Ajouter le code client dans Power PDF ouvre la fenêtre du store avec ce code déjà saisi. Si vous installez l'Add-on Store avec le téléchargement d'une telle page, la fenêtre du store s'ouvre une fois au prochain démarrage de Power PDF avec le code déjà saisi. Dans les deux cas, vous ajoutez vous-même le code avec Ajouter un code ; rien n'est ajouté sans vous.

Liens depuis le site web, installation manuelle

« Installer dans Power PDF »

Sur le site web du store, chaque module dispose du bouton Installer dans Power PDF. Grâce au lien addonstore://, il ouvre la fenêtre du store sur ce module et demande s’il faut l’installer ; si Power PDF est encore en cours de démarrage, le client attend que sa fenêtre principale soit affichée. Un site web peut uniquement ouvrir la fenêtre de cette façon, jamais installer quoi que ce soit de lui-même. Si le module ne figure pas dans le catalogue, la fenêtre indique « Le module « … » du site web ne figure pas dans le catalogue. Il est peut-être disponible uniquement dans le canal bêta (Options). »

Installation manuelle sans le client

Pour les ordinateurs sans client, le site web propose Manuel (ZIP) pour chaque module public : un fichier ZIP contenant install.bat, uninstall.bat et des instructions. install.bat vérifie la signature et la somme de contrôle, demande une seule fois des droits d’administrateur et crée le groupe dans le ruban ; /quiet installe sans poser de questions, pour la distribution de logiciels. Une installation manuelle ne reçoit ni mises à jour ni blocages de sécurité. Si le client est installé ultérieurement, il reconnaît le module et le tient à jour. Lorsque le client supprime un tel module, il efface aussi son entrée sous Applications installées ; lorsqu’il le met à jour, il met à jour la version qui y est affichée.

Pour les administrateurs

Déploiement

Le MSI s’installe par machine et s’exécute en mode silencieux, de préférence dans une étape distincte juste après Power PDF (Intune, SCCM, GPO, scripts) :

msiexec /i PluginStore.msi /qn /norestart /l*v "%TEMP%\AddonStore.log"

  • Power PDF doit être installé au préalable. Peu importe qu’il ait déjà été démarré ou non.
  • Le programme d’installation refuse de s’exécuter si Power PDF est absent, antérieur à 2025.3.7 (vérifié avec VersionLong dans HKLM\SOFTWARE\Kofax\PDF\V1), s’il s’agit d’une édition sans modules avant 2026.4, ou s’il est sous licence avec un numéro de série. Dans ce dernier cas, la propriété ALLOWNONSAAS=1 permet tout de même l’installation.
  • Pour imposer une langue, utilisez TRANSFORMS=:<LCID>, par exemple TRANSFORMS=:1031 pour l’allemand.
  • Règle de détection Intune : le fichier <bin>\Plug-Ins\PluginStore.zxt avec une version minimale (le ProductCode change à chaque version).
  • Une nouvelle installation (et non une mise à jour) nettoie une fois par utilisateur les restes de modules supprimés dans l’onglet Fonctions avancées ; les modules installés y ajoutent à nouveau leurs groupes à leur prochain démarrage.
  • Lorsque le service informatique déploie lui-même le MSI, DisableSelfUpdate désactive la mise à jour automatique.

Stratégies

Toutes les stratégies se trouvent sous HKLM\SOFTWARE\Kofax\PDF\Tungsten Power PDF\PluginStore\Policies\Store (vue 64 bits ; depuis des agents de déploiement 32 bits, utilisez reg add … /reg:64). Elles priment sur les paramètres de l’utilisateur et verrouillent les champs correspondants de la page d’options. Les valeurs DWORD peuvent aussi être définies sous forme de texte, par exemple « 1 » (REG_SZ). Le client les lit au démarrage de Power PDF.

ValeurTypeEffet

BetaChannelDWORD1 = afficher les versions bêta, 0 = ne pas les afficher.

DisableInstallDWORD1 = consultation uniquement : aucune installation, mise à jour ou suppression de modules.

Journaux

  • %TEMP%\PluginStore.log : journal du client et de ses étapes auxiliaires (redémarrage, mise à jour automatique, basculement vers la seconde adresse). Davantage de détails avec Journalisation détaillée.
  • %WINDIR%\Temp\AddonStoreUpdate-<id>.log : le journal MSI d’une mise à jour automatique.

Réseau

  • Une seule règle de pare-feu suffit : HTTPS (port 443) vers le serveur du store, via le proxy du système (détection automatique du proxy WinHTTP). TLS 1.2 ou ultérieur, aucune redirection, aucun autre hôte, même si le catalogue en indiquait un.
  • Avec l’adresse intégrée, la règle nécessite deux noms : addon.power-pdf.de et ppdf-store.azurewebsites.net.
  • Seconde adresse : lorsqu’une requête vers https://addon.power-pdf.de échoue (pas de connexion, erreur TLS ou de certificat, réponse interrompue, erreur HTTP), le client l’envoie une fois à https://ppdf-store.azurewebsites.net, mais seulement après que cet hôte s’est identifié comme Add-on Store (GET /api/ping). Il y reste ensuite pour la session en cours et réinterroge l’adresse principale toutes les 10 minutes. Une requête POST susceptible d’avoir atteint le serveur n’est jamais envoyée deux fois. Ce mécanisme ne s’applique qu’avec l’adresse intégrée, et non avec ServerUrl ou une autre adresse définie dans les options.
  • Vérifications en arrière-plan : autorisation de la licence 3 secondes après le démarrage puis toutes les 4 heures, liste de blocage après 20 secondes puis toutes les 4 heures, mises à jour après environ 15 secondes et après la fermeture de la fenêtre du store.

Confidentialité

Le client n’envoie aucun document, ni aucun nom d’utilisateur ou d’ordinateur. Chaque requête transmet des données techniques au serveur du store :

  • l’identifiant du programme avec les versions du client, de Power PDF et de Windows ainsi que l’architecture du processeur, par exemple AddonStore-PowerPDF/2.4.0 (PowerPDF …; Windows …; x64) ;
  • le mode de licence de Power PDF (cloud, serial ou unknown), afin que le store puisse vérifier s’il peut être utilisé ;
  • uniquement avec un code client : les codes et un identifiant d’installation aléatoire de cet utilisateur ; le serveur n’en conserve qu’une valeur de contrôle par livraison.

Les évaluations utilisent le même identifiant aléatoire ; le serveur n’en conserve qu’une valeur de contrôle par module. Les signalements contiennent ce que vous saisissez et joignez, ainsi que les versions du module, de Power PDF et de Windows.

Une fois par jour, le client envoie un rapport d’inventaire : l’identifiant d’installation aléatoire, le domaine de la connexion à Power PDF (uniquement la partie après le @, jamais l’adresse ; les domaines des services de messagerie publics ne sont pas transmis), le mode de licence, les versions de Power PDF et du client, ainsi que les modules installés avec leurs versions. Le serveur ne l’exploite que si ses administrateurs ont activé cette analyse. La stratégie Inventory = 0 désactive ce rapport.

Clarifiez cette utilisation avec votre délégué à la protection des données ; pour les données stockées sur le serveur, c’est la déclaration de l’exploitant du serveur du store qui s’applique.

Sécurité

  • Seuls les paquets signés par une clé de store de confiance sont installés (intégrées : la clé du store et une clé de secours ; d’autres clés uniquement via la stratégie TrustedSigningKeys, jamais via HKCU).
  • L’étape avec droits d’administrateur lance Windows PowerShell par son chemin complet, avec le script en mémoire. Elle copie d’abord le paquet dans un dossier situé sous Plug-Ins, où seuls les administrateurs ont le droit d’écrire, y vérifie à nouveau la somme de contrôle et ne le décompresse qu’ensuite.
  • La fenêtre du store affiche une page intégrée au client. Elle ne charge rien depuis Internet, ne peut pas naviguer et ne communique avec le client que par messages ; les données s’affichent uniquement sous forme de texte.
  • L’assistant de liens AddonStoreLink.exe ne transmet qu’un identifiant de module vérifié ; rien n’est installé avant votre confirmation.

Questions fréquentes

Les modules sont-ils des produits officiels de Tungsten Automation ?

Non. Ils proviennent de développeurs indépendants et sont fournis sans garantie et sans support officiel ; voir Avertissement. L’auteur indiqué dans le catalogue répond aux questions.

Pourquoi ai-je besoin de droits d’administrateur ?

Les modules se trouvent dans le dossier du programme Power PDF, sous Program Files, où seuls les administrateurs ont le droit d’écrire. C’est pourquoi le store demande l’autorisation une fois par action.

Pourquoi Power PDF doit-il redémarrer ?

Power PDF ne charge les modules qu’au démarrage et ne les libère qu’à sa fermeture.

Le store voit-il mes documents ?

Non. Le client n’envoie aucun document ; le chapitre Pour les administrateurs répertorie tout ce qu’il transmet.

Puis-je revenir à une version plus ancienne d’un module ?

Le store n’installe pas de versions plus anciennes. Supprimez le module et contactez son auteur.

Le store fonctionne-t-il sans Internet ?

Les modules installés continuent de fonctionner. La fenêtre affiche le dernier catalogue chargé ; l’installation et la mise à jour fonctionnent à nouveau dès que la connexion est rétablie.

Comment obtenir des modules créés pour mon entreprise ?

Avec le code client de votre fournisseur (chapitre Codes client), ou bien le service informatique le définit par stratégie.
